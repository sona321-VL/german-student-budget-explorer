# 🇩🇪 German Student Budget Explorer

## 📌 Project Overview

The German Student Budget Explorer is a Python-based Data Science project designed to help international students estimate and compare monthly living expenses across different cities in Germany.

Users can select a city, enter their monthly budget, explore expense categories, and compare estimated living costs using an interactive dashboard.

## 🎯 Objectives

- Estimate monthly student living expenses.
- Compare budgets across German cities.
- Analyze major expense categories such as rent, food, transport, and health insurance.
- Visualize spending patterns using charts.
- Help students plan their finances before studying in Germany.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
- Jupyter Notebook
- Git and GitHub

## ✨ Features

- Interactive city selection
- Monthly budget calculator
- Remaining-budget calculation
- Expense category visualization
- Comparison of estimated expenses across cities

## 📊 Expense Categories

- Rent
- Food
- Transport
- Health insurance
- Phone
- Personal expenses

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd german-student-budget-explorer
```

### 2. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 3. Run the application

```bash
python -m streamlit run app.py
```
